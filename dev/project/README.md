# dev/project/ ✏️ — โค้ดของคุณ (contract)
- `contracts/` Solidity ของคุณ กี่ไฟล์ก็ได้ (`mocks/` = contract ที่ใช้แค่ทดสอบของโปรเจกต์นี้)
- `test/<ชื่อ>.test.mjs` เทส แยกไฟล์ต่อ contract/เรื่อง ทุกไฟล์เริ่มจากเชนสะอาด (`npm test`)
- `seed.mjs` ข้อมูลตัวอย่างตอน `npm run dev` + ตัวช่วยที่เทสใช้ซ้ำ
- `devActions.js` ปุ่มในแผงทดสอบที่ใช้ **เฉพาะโปรเจกต์นี้** (ปุ่มที่ทุกโปรเจกต์ใช้อยู่ใน engine แล้ว)
